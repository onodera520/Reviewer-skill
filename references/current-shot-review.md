# 静态图提示词符合性

每次按 [预览审查口径](story-preview.md) 执行。逐张绑定用户提供的图片与对应提示词原文；核对人物、场景、关键道具、构图及动作意图。Shot Spec、资产、剧情及相邻镜头补充背景，不静默覆盖提示词。影响判断的来源冲突列为待确认。

## 先判断主要意思是否成立

拿起便当可以由伸手、抓取、正在提起表达，不因饭盒尚未离层板、微小手势或非关键手别单独报错。只有人物错误、关键对象错误、方向相反、核心道具缺失、明显妨碍理解的构图或必要剧情结果错误才提出修改。明确完成交接的结果不能用准备交接替代。普通服饰纹理、商品排列及轻微曝光差异放行。

没有对应提示词时只能做有限视觉和连续性审查，当前符合性 uncertain，列至少 medium 待确认；没有 Spec 不阻止凭提示词审图。多阶段动作不默认缺证，只有无法确认影响剧情理解的目标或结果时才请求补证。不检查音频、水印，也不做字幕专项检查或 OCR。

## 证据与归因

实际看图后才能确认错误。单镜 issue 至少提供对应 `image_prompt` 与当前图像证据，版本已知时保留 source_version。技术 error_type 仍可用 `shot_spec_compliance`，新报告展示为“提示词符合性”。缺输入不是确认错误。

合理离画、遮挡不证明物体消失。提示词要求展示关键对象而图片错误裁切时，报告构图影响，不声称世界中的物体消失。相邻检查读取 [连续性模块](continuity-review.md)，错误前图不迫使正确当前图复制错误。

同因同时违反提示词与连续性时只建一个 issue，以 related_review_areas 关联两项，提供两套依据。动作意图通过不代表完成状态已被观察，持久状态仅记录有证据的事实。

## 数量问题确认门槛

怀疑关键物体复制、消失或数量错误时，先查看原始分辨率的相关局部，不能仅凭缩略图判错。可裁切原图检查，但不能用生成式补全或超分辨率猜出的细节作为证据。普通、无关剧情的细节不触发全面放大检查。

对盒装物品逐个核对独立盒体的盖沿、底座、外轮廓和遮挡关系，明确哪些边缘属于同一物体。餐格、包装带、标签、反射、阴影、透明盒内部隔层不得直接计为独立物体；两盒叠放形成四条边缘不等于四盒。消失判断仍须确认原有位置清晰可检验，不能将遮挡当作缺失。

判为 high / critical 前，必须核实提示词或可信剧情的数量要求、实际独立物体证据，并说明数量差异的剧情影响。轮廓因遮挡或低清无法确认时标记 uncertain，不能改报低等级绕过确认门槛，也不能将尚未确认的数量写入持久状态。

复用 evidence 的 locator / observation 记录原图局部位置、独立盒体及结构辨识依据；未实际查看原始局部不得声称完成该步骤。能确认的数量与无法确认的隐藏部分分别描述，不以预期数量代替观察。

## 修改方案

提示词明确但图片执行错误，优先局部修正或重新生成指定镜头。只有提示词确有歧义或约束不足时才给可直接使用的增补或替换文字。不得通过更改机位、景别、人物安排掩盖错误。默认成品只呈现问题、严重程度和修改方案，内部仍保留完整证据。

没有 review_profile 的历史记录仍按原 Spec 合规语义读取，不套用新尺度追溯改判。
