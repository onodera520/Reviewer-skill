# Reviewer 分镜审查

Reviewer 按用户提供的对应图片提示词核对静态图，以故事预览是否清楚为判定尺度，也检查明显连续性穿帮。

它能审查两种素材：

- 静态分镜图。
- 智能分镜：把多个分镜按剧情顺序快速串起来的预览视频。

它不会生成图片或视频，也不会替你重新设计镜头。它只找出实际素材中的问题，并给出修改方向。

## 它会检查什么

### 静态分镜图

- 这张图是否清楚表达对应提示词的人物、对象、构图和动作意图。
- 人物的身份、衣服、发型、伤势和状态是否前后一致。
- 手机、便当、武器等重要道具有没有无故消失、出现或换到别人手上。
- 门、窗、货架、桌面、灯光、天气等场景内容有没有无故变化。
- 人物和重要物体的实际空间关系有没有穿帮。

它会先判断某个东西在这一镜里是否本来就该看得见。因此，近景裁掉货架、人物挡住道具、反打让画面左右对调，都不会被直接当成错误。

### 智能分镜视频

- 视频中的人物、道具、构图和场景是否延续对应分镜图。
- 小幅动作是否表达了镜头想表达的事情，例如看向谁、递给谁、开门后门是否真的打开。
- 人物、道具或背景是否在镜头中突然漂移、替换或变形。
- 镜头是否按剧情顺序出现，镜头之间是否直接硬切。
- 关键因果和必要结果是否成立。

不检查音频、水印，不做字幕专项检查或 OCR。只有文字遮住关键动作、妨碍理解时才报告。默认每镜检查首、中、尾及必要切点，有实质疑点才加密。

“拿起便当”可以通过伸手、抓取或正在提起表达，不纠结是否已经离开层板；但拿错对象或交接后持有者错误仍会报告。

## 你需要提供什么

提供得越完整，审查越准确：

- 每张图片对应的原始图片提示词，并标明对应关系。
- 生成的分镜图。
- 前后连续镜头的分镜图和描述。
- 需要审查视频时，提供视频和对应的分镜图。
- 人物、场景或重要道具的参考图（如果有）。

你不需要自己填写 JSON。缺少对应提示词时只能做有限视觉及连续性检查；Shot Spec 和资产用于补充背景，影响判断的冲突会列为待确认。

## 你会得到什么

默认会得到一份简洁的中文 Markdown 报告，方便直接交给生成或剪辑环节处理。

每个问题只说明：

```text
问题：当前货架为空，应保持满载商品陈列。
严重程度：中
修改方案：局部修正当前分镜的货架陈列，恢复满载状态。
```

视频问题会额外标出受影响镜头、视频时间范围，以及应修改视频、剪辑还是源分镜图。提示词已明确时优先修正生成结果；只有提示词有歧义或约束不足时才建议修改提示词。

## 安装

将整个 `reviewer` 文件夹放到 Codex 的个人 Skills 文件夹中：

```text
%USERPROFILE%\.codex\skills\reviewer
```

第一次使用时，按以下命令安装所需组件：

```powershell
python -m pip install -r scripts/requirements.txt
```

审查智能分镜视频还需要本机具备视频读取工具。具体配置方法见 [智能分镜审查说明](references/animatic-review.md)。
