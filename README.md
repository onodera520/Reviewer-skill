# Reviewer 分镜审查

Reviewer 用来检查 AI 生成的分镜是否符合原来的镜头设计，也会检查连续镜头之间有没有穿帮。

它能审查两种素材：

- 静态分镜图。
- 智能分镜：把多个分镜按剧情顺序快速串起来的预览视频。

它不会生成图片或视频，也不会替你重新设计镜头。它只找出实际素材中的问题，并给出修改方向。

## 它会检查什么

### 静态分镜图

- 这张图是否符合当前镜头的描述。
- 人物的身份、衣服、发型、伤势和状态是否前后一致。
- 手机、便当、武器等重要道具有没有无故消失、出现或换到别人手上。
- 门、窗、货架、桌面、灯光、天气等场景内容有没有无故变化。
- 人物和重要物体的实际空间关系有没有穿帮。

它会先判断某个东西在这一镜里是否本来就该看得见。因此，近景裁掉货架、人物挡住道具、反打让画面左右对调，都不会被直接当成错误。

### 智能分镜视频

- 视频中的人物、道具、构图和场景是否延续对应分镜图。
- 小幅动作是否表达了镜头想表达的事情，例如看向谁、递给谁、开门后门是否真的打开。
- 人物、道具或背景是否在镜头中突然漂移、替换或变形。
- 镜头是否按剧情顺序出现，镜头之间是否直接硬切。
- 是否出现不该有的字幕、台词、旁白或音乐。

环境声和动作音效可以保留。如果声音无法可靠判断，报告会写明“待确认”，不会凭感觉下结论。

## 你需要提供什么

提供得越完整，审查越准确：

- 每个镜头的文字描述。
- 生成的分镜图。
- 前后连续镜头的分镜图和描述。
- 需要审查视频时，提供视频和对应的分镜图。
- 人物、场景或重要道具的参考图（如果有）。

你不需要自己整理复杂表格。直接提供脚本、镜头描述、图片和视频即可。

## 你会得到什么

默认会得到一份简洁的中文 Markdown 报告，方便直接交给生成或剪辑环节处理。

每个问题只说明：

```text
问题：当前货架为空，应保持满载商品陈列。
严重程度：高
修改方案：重新生成当前分镜，恢复既定货架状态。
```

视频问题会额外标出受影响镜头、视频时间范围，以及应修改视频、剪辑、声音还是源分镜图。

## 安装

将整个 `reviewer` 文件夹放到 Codex 的个人 Skills 文件夹中：

```text
%USERPROFILE%\.codex\skills\reviewer
```

第一次使用时，按以下命令安装所需组件：

```powershell
python -m pip install -r scripts/requirements.txt
```

审查智能分镜视频还需要本机具备视频读取工具。具体配置方法见 [智能分镜审查说明](references/animatic-review.md)。
